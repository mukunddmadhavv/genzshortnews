# FFmpeg recipes

**Default design:** `approved-format.md` governs all new output. Follow
`scripts/build_image_preview.py` for the image-only upper panel, then composite
with `scripts/render_short.py`. Caption recipes below are available only if the
user explicitly requests captions; do not add them to the approved default.

Run from the project root. Create each output's parent directory first. Commands
use sample filenames that must be replaced with existing episode assets.

## Reference download (separate subtitles from video)

```sh
uvx --from yt-dlp yt-dlp --no-playlist --write-info-json --no-write-subs --no-write-auto-subs --merge-output-format mp4 -f 'bv*+ba/b' -o 'references/neonman/CFZ6qULa8dU.%(ext)s' 'https://www.youtube.com/shorts/CFZ6qULa8dU'
```

Caption downloads can fail with HTTP 429 without meaning the video is inaccessible.
Do not repeatedly request blocked captions; use the downloaded audio for ASR.

## Make a still into an editorial beat

```sh
ffmpeg -n -loop 1 -framerate 30 -i episodes/story/visuals/card.png -t 4.0 -vf 'scale=1080:810:force_original_aspect_ratio=decrease:force_divisible_by=2,pad=1080:810:(ow-iw)/2:(oh-ih)/2:black,setsar=1,format=yuv420p' -an -c:v libx264 -crf 18 episodes/story/beat-01.mp4
```

For a video beat, use `-ss START -i source.mp4 -t DURATION` and the same
scale/pad/fps settings. Export all beats at the same resolution/fps/codec before
concatenating. A concat list file contains lines like `file 'beat-01.mp4'` with
paths relative to that list. Use simple controlled filenames.

```sh
ffmpeg -n -f concat -safe 0 -i episodes/story/beats.txt -c copy -an episodes/story/news-panel.mp4
```

## Render the complete split-screen Short

```sh
uv run --with pillow scripts/render_short.py --news episodes/story/news-panel.mp4 --gameplay library/gameplay/driving/car-track-01.mp4 --gameplay-start 12 --narration episodes/story/narration.mp3 --headline "THE DETAIL EVERYONE MISSED" --channel "YOUR CHANNEL" --font "/System/Library/Fonts/Supplemental/Arial Bold Italic.ttf" --out episodes/story/final.mp4
```

Choose an installed `.ttf`/`.otf` font on other platforms. The compositor makes
Pillow branding PNGs because this machine's FFmpeg lacks `drawtext` and `subtitles`.
It contains news visuals, crops gameplay, adds original bars, mutes source audio,
mixes narration/optional SFX, limits duration to narration and writes a manifest.
The upper-panel sequence must already be assembled; captions and CTA animation
are not automatically generated by this helper.

Optional `--sfx-cues episodes/story/sfx-cues.json`:

```json
[
  {"file": "../../library/sfx/ui-pop.mp3", "start_seconds": 3.2, "gain_db": -16},
  {"file": "../../library/sfx/whoosh.mp3", "start_seconds": 21.1, "gain_db": -18}
]
```

Effects use timestamps relative to the narration start. Gain is relative to each
source file, not a guaranteed loudness difference; normalize/audition source SFX.
The final single-pass loudnorm is a starting normalization. Measure final output.

## Optional music bed

Keep music separate from gameplay. When adding it to the compositor, split the
voice, feed one branch to `sidechaincompress`, then mix the other branch with the
ducked bed and SFX. For example, this filter shape assumes normalized voice/bed:

```text
[voice]asplit=2[voice_mix][voice_key];
[bed]volume=0.08[quiet_bed];
[quiet_bed][voice_key]sidechaincompress=threshold=0.02:ratio=6:attack=10:release=250[ducked];
[voice_mix][ducked]amix=inputs=2:duration=first:normalize=0[mix]
```

This is a filter recipe, not implemented music support in `render_short.py`.

## Captions without drawtext/libass

From final speech alignment, group 3–6 readable words and render each phrase as a
transparent PNG. For every caption, add a PNG input and overlay using
`enable='gte(t,START)*lt(t,END)'`. Normalize timestamps and use a fixed reserved
caption area near the panel seam. For many captions, pre-render a transparent
caption layer to avoid hundreds of simultaneously-open inputs. Strip performance
tags from display text. Caption generation is a documented next production step.

## Verify

```sh
ffprobe -v error -show_format -show_streams -of json episodes/story/final.mp4
ffmpeg -v error -i episodes/story/final.mp4 -f null -
ffmpeg -hide_banner -i episodes/story/final.mp4 -vn -af 'loudnorm=I=-16:TP=-1.5:LRA=7:print_format=json' -f null -
```

Check measured `input_i` and `input_tp`, which describe the encoded file. For
two-pass normalization, use those measured values plus `input_lra`, `input_thresh`
and `target_offset` in a second loudnorm pass with `measured_I`, `measured_TP`,
`measured_LRA`, `measured_thresh`, `offset`, `linear=true`. Recheck the encoded
result; do not copy measurement values from the reference into another episode.
