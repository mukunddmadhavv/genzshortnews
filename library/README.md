# Reusable gameplay and sound effects

Place your recorded/permitted footage into the game-specific folders. The library
is intentionally folder-based, without a database. A collection of 15 downloaded
1080p gameplay excerpts is available in `gameplay/`; see
[the collection and source credits](gameplay/COLLECTION.md). The downloaded news
reference is stored separately.

Prefer continuous recordings long enough for an entire episode, with clean
gameplay and no menus/facecam. Original game audio is muted by the renderer.
Save source/permission notes beside third-party assets where applicable.

Put generated reusable ElevenLabs effects in `sfx/`. Per-episode cue files store
timing and gain; the library does not need a separate index.
